# Restauração das imagens

Ferramenta: ImageGen integrada, modo de edição a partir das fotografias originais. Os arquivos PNG em imagens-restauradas são os resultados da edição; imagens-originais guarda os arquivos de origem. As versões WebP do site são exportações desses resultados. A restauração é generativa e pode reconstruir pequenos detalhes; não equivale a recuperar um negativo original.
